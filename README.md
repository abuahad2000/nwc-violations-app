# نطاق — متابعة التعديات والمشاريع

واجهة عربية مبنية على Next.js، تضم مؤشرات وشارتات مديري المشاريع، خريطة OpenStreetMap، استيراد Excel بمعاينة واعتماد، صلاحيات المستخدمين، وإدارة الإجراءات والتصدير.

## الأوامر الرئيسية

من جذر المستودع: `npm run setup` ثم إعداد ملف الاتصال وفق دليل التشغيل، ثم `npm run build` و`npm start`.

لفحص المشروع: `npm run lint` و`npm run typecheck` و`npm test`.

هذا المستودع للكود والاختبارات الاصطناعية فقط؛ تبقى قواعد البيانات وملفات Excel وKMZ وبيانات الدخول في التخزين الخاص.
