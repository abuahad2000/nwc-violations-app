# أدوات المشروع

تُشغّل الأوامر التالية من `apps/web`، حتى تبقى مسارات البيانات والعمل متسقة. استخدم أوامر npm بدل تشغيل الملفات من داخل المجلدات الفرعية.

| المجال | الأمر | النتيجة |
|---|---|---|
| الحسابات | `npm run admin:init` | إنشاء أول مدير فقط، باستخدام متغيرات البيئة الموضحة في دليل التشغيل |
| التشغيل | `npm run start:local` | فحص PostGIS وتشغيل التطبيق محليًا |
| البيانات | `npm run backup` | نسخة متسقة لقاعدة البيانات مع فحص سلامتها |
| البيانات | `npm run import:local` | معاينة ملف التعديات دون اعتماده |
| البيانات | `npm run import:local -- --commit <preview_id>` | اعتماد معاينة محددة |
| المراجع | `npm run reference:prepare` | قراءة Excel وKMZ وإنشاء ملف مراجعة خاص |
| التصنيف | `npm run repair:local` | تطبيق قواعد الاعتماد والإصلاح المحلية؛ لا يُشغّل على مرجع جديد قبل مراجعته |
| الاختبار | `npm run test:setup` | تهيئة بيانات اصطناعية؛ يتطلب `NWC_DATA_DIR` بمجلد ينتهي بـ`nwc-repair-e2e` |

مجلد `build` يستدعيه `predev` و`prebuild` تلقائيًا. أدوات `diagnostics` تقرأ بيانات محلية وقد تعرض أجزاء منها في الطرفية؛ ليست مسارات عامة أو مهام نشر. تحتفظ `data/import-local-data.mjs` و`data/init-db.mjs` بأدوات التهيئة القديمة داخل التنظيم الجديد.
