# دليل الاختبارات

- `unit/`: الأعمار والصلاحيات والقواعد المكانية المساعدة وتجميع أرقام المديرين.
- `integration/`: الاستيراد والفلاتر وتهيئة الإدارة وPostGIS الحقيقي.
- `e2e/`: الدخول والصلاحيات والاستيراد والشارتات والتصدير والجوال في المتصفح.
- `fixtures/`: ملفات اصطناعية فقط، ومنها صورة خلفية الخريطة للاختبارات المتكررة.

من `apps/web`:

```text
npm test
npm run test:db
```

يحتاج `test:db` إلى `.env.local` يحوي اتصال PostGIS. تُتخطى اختبارات PostGIS إن لم يُقدّم الاتصال في التشغيل العام؛ التخطي لا يساوي نجاح اختبار المحرك.

لاختبارات المتصفح على Windows، في طرفية مستقلة:

```powershell
$env:NWC_DATA_DIR = Join-Path $env:TEMP 'nwc-repair-e2e'
npm run test:setup
npm run dev -- --hostname 127.0.0.1 --port 3107
```

ثم من طرفية أخرى داخل `apps/web`: `npm run test:e2e`. لتوجيه الاختبارات إلى بناء إنتاج اختباري مختلف، اضبط `PLAYWRIGHT_BASE_URL` قبل تشغيلها. لا توجه الاختبارات إلى قاعدة تشغيلية أو المنفذ3100 الخاص بعمل المستخدم.
