# بنية التطبيق

| المسار | المسؤولية |
|---|---|
| `app/` | صفحات Next.js؛ `app/api/` للتحقق من المدخلات والصلاحيات وإرجاع النتائج |
| `components/` | واجهة العرض: لوحة المتابعة، شارتات المديرين، الخريطة، الجداول والتفاصيل |
| `components/ui/` | مكونات واجهة عامة مثل اللوحة الجانبية |
| `lib/auth/` | الدخول والجلسات والأدوار والتحقق من مصدر الطلب |
| `lib/db/` | التخزين المحلي وإصلاحات المخطط؛ `migrations/` مرجع مخطط PostgreSQL |
| `lib/domain/` | الفلاتر والأعمار وتجميع مؤشرات المديرين |
| `lib/imports/` | فحص ملفات Excel والمعاينة والاعتماد وحفظ نسخ المصدر |
| `lib/spatial/` | مرجع المشاريع واعتماد الحدود وتصنيف PostGIS |
| `types/` | أنواع مشتركة بين أجزاء التطبيق |

تعديل قاعدة عمل مشتركة يكون في `lib`، وليس بنسخها داخل صفحات متعددة. يُراجع نطاق المستخدم على الخادم لكل مسار بيانات؛ إخفاء زر في الواجهة لا يمنح حماية بحد ذاته.
