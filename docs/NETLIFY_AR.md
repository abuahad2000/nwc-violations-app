# Netlify وNeon

المستودع `abuahad2000/nwc-violations-app` مرتبط بمشروع Netlify بالاسم نفسه وفرع الإنتاج `master`.

## البناء

يحدد `netlify.toml` المجلد الأساسي `apps/web` وأمر `npm run build` ومجلد النشر `.next` وNode.js 24. محوّل `@netlify/plugin-nextjs` مفعّل صراحةً لأن إعداد الموقع السابق كان ثابتًا. لا تستخدم `start:local` في Netlify؛ هذا أمر خاص بتشغيل الجهاز.

## قاعدة البيانات

تستخدم نسخة الخادم PostgreSQL عند وجود `DATABASE_URL`. يستخدم التصنيف المكاني الاتصال نفسه، أو `POSTGIS_URL` عند تحديد خدمة مكانية منفصلة. جميع الاتصالات داخل الخادم؛ لا تضف بادئة `NEXT_PUBLIC_` إلى أسرار الاتصال.

تم إنشاء مشروع Neon باسم `nwc-violations-app` بالخطة Free في AWS Ohio. حدود الخطة المعروضة عند الإعداد: 0.5 GB تخزين، و100 CU-hours، و5 GB نقل شهري. تتوقف الحوسبة أثناء الخمول، وقد يتأخر أول اتصال عند الاستيقاظ. لا توجد ترقية مدفوعة ضمن هذا الإعداد.

في Netlify يُحفظ `DATABASE_URL` كقيمة سرية في سياق Production. لا تشارك قاعدة الإنتاج مع معاينات طلبات السحب. يحتاج كل سياق اختبار قاعدة منفصلة قبل تمكين تسجيل الدخول فيه.

## الترحيل الأول فقط

من `apps/web` شغّل `scripts/data/migrate-cloud.ts` بواسطة Node وtsx مع متغيري `DATABASE_URL` و`NWC_MIGRATION_SOURCE` الذي يشير إلى ملف SQLite الخاص. السكربت يقرأ المصدر دون تعديله، ويطبّق `002_cloud_runtime.sql`، ويرفض الاستبدال إذا احتوت قاعدة الوجهة على مستخدمين. ينقل الجداول داخل معاملة واحدة ويطابق أعداد الصفوف قبل الاعتماد. لا ينقل جلسات الدخول أو محاولات الدخول أو معاينات الاستيراد المؤقتة.

ملف `001_initial_schema.sql` تصميم سابق مختلف، وليس مخطط نسخة التشغيل الحالية. لا تطبّقه فوق مخطط الترحيل الحالي.

تستخدم المعاملات اتصالًا واحدًا مع عزل SERIALIZABLE. عند تعارض تعديلين يُرفض أحدهما بدل فقد التعديل؛ حدّث البيانات وأعد المحاولة. تُحفظ الحسابات والجلسات والإجراءات في PostgreSQL وتبقى بعد إعادة نشر الموقع.

## التشغيل المحلي والاختبار

دون `DATABASE_URL` تبقى نسخة الجهاز على SQLite. تبقى أوامر الملفات المحلية مثل قراءة Excel من مجلد الجهاز ومزامنة ملف المرجع المحلي خاصةً بالجهاز؛ الاستيراد السحابي يستخدم رفع الملف عبر الواجهة.

`npm test` يفحص المنطق والاستيراد المحلي. يفعّل `NWC_TEST_POSTGRES_URL` اختبارات PostgreSQL في مخطط مؤقت منفصل يُحذف بعد الاختبار، دون تعديل جداول التشغيل. تغطي الاختبارات اعتماد المعاملة والتراجع الكامل واستقلال الاتصالات وتعارض التحديثات.

المفاتيح وملفات `.env*` وقواعد SQLite وملفات Excel وKMZ مستثناة من Git. يلزم عمل نسخ احتياطية مستقلة لبيانات PostgreSQL؛ نسخ SQLite المحلية لا تشمل تعديلات الموقع السحابي.
