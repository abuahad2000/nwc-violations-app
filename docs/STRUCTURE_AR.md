# خريطة المشروع

```text
nwc-violations-app/
├── README.md                 نقطة البداية وروابط الأدلة
├── package.json              أوامر موحدة من جذر المشروع
├── docs/                     التشغيل وبنية الملفات
├── apps/web/                 تطبيق الويب
│   ├── src/                  صفحات الواجهة ومنطق الخادم
│   │   ├── app/              الصفحات ومسارات API وفق Next.js
│   │   ├── components/       الشارتات والخريطة والجداول والمكونات المشتركة
│   │   ├── lib/              المصادقة والبيانات والاستيراد والتصنيف
│   │   └── types/            الأنواع المشتركة
│   ├── scripts/              أدوات الإدارة والتشغيل حسب الوظيفة
│   │   ├── accounts/         تهيئة الحسابات وإدارتها
│   │   ├── data/             الاستيراد والنسخ الاحتياطي وتهيئة البيانات
│   │   ├── spatial/          إعداد المراجع والتصنيف المكاني
│   │   ├── runtime/          بدء التشغيل وفحص المتطلبات
│   │   ├── build/            تجهيز ملفات الخريطة للبناء
│   │   ├── diagnostics/      فحص مصادر البيانات محليًا
│   │   └── testing/          تجهيز بيانات الاختبار الاصطناعية
│   ├── tests/
│   │   ├── unit/             اختبارات قواعد الحساب والصلاحيات
│   │   ├── integration/      اختبارات التخزين والاستيراد وPostGIS
│   │   ├── e2e/              سيناريوهات المتصفح
│   │   └── fixtures/         ملفات اصطناعية مساعدة
│   └── .env.example          نموذج إعدادات دون أسرار
├── .vscode/                  إعدادات المحرر للمشروع
└── .agents/                  قواعد وأدوات المساعدة الخاصة بالمشروع
```

تبقى ملفات إعداد Next.js وTypeScript والاختبارات داخل `apps/web` في مواقعها القياسية. توضع قواعد العمل في `src/lib`، ويقتصر `scripts` على أدوات تُشغّل يدويًا أو أثناء البناء.

المجلدات `.next` و`node_modules` و`public/maplibre` مولدة وليست ملفات مصدر. مجلدات `data` و`excel` و`kmz` و`backups` وملفات `.env.local` خاصة ومستبعدة من Git.
