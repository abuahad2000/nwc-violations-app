# البنية المحلية

تشغّل `docker-compose.yml` أربع خدمات:

- PostGIS على المنفذ 5432.
- FastAPI على `http://localhost:8000`.
- Next.js على `http://localhost:3000`.
- pg_tileserv اختياري على `http://localhost:7800`.

## التشغيل

من جذر المستودع:

```powershell
docker compose up --build
```

القيم الافتراضية مخصصة للتشغيل المحلي فقط. في بيئة النشر يجب تمرير بيانات الاتصال عبر أسرار المنصة، وعدم وضعها في المستودع.

## قاعدة الربط

الدالة `suggest_nearest_project` تعيد أقرب مشروع جارٍ داخل 50 مترًا كمرشح مراجعة. لا تعدّل البلاغ ولا تعيّن `project_id` تلقائيًا. الاعتماد الفعلي يبقى لنتيجة `ST_Contains` داخل نطاق KMZ الجاري المعتمد، مع تطابق المقاول بعد التنظيف والمطابقة الدقيقة.
